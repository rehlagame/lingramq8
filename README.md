# مدونة Lingram (lingramq8) للأخبار التقنية - إصدار 2026

مرحباً بك في **Lingram**، منصة إخبارية تقنية متطورة بتصميم **2026** متخصصة في تغطية عالم التكنولوجيا، الذكاء الاصطناعي، الأمن السيبراني، وألعاب الفيديو.

## أبرز المميزات الجديدة (تحديث 2026)

- **تصميم Bento Grid & Glassmorphism:** واجهة عصرية تدعم الوضع الداكن (OLED Dark Mode) والوضع الفاتح مع انتقالات سلسة وخطوط عربية هندسية (`IBM Plex Sans Arabic`).
- **محرك أخبار هجين (RSS + NewsAPI):** يجمع الأخبار من أشهر المصادر التقنية العربية الموثوقة (البوابة العربية للأخبار التقنية، عالم التقنية، التقنية بلا حدود، سعودي جيمر، ترو جيمنج، عرب هاردوير) إلى جانب `NewsAPI`.
- **حفظ كامل لحقوق النشر والمصادر:** كل بطاقة خبر وصفحة تفاصيل تعرض بوضوح اسم المصدر الأصلي، الكاتب، تاريخ النشر، مع بطاقة توثيق قانونية ورابط مباشر لقراءة المقال من موقعه الأصلي.
- **الموجز الصوتي الذكي (Audio Briefing):** إمكانية الاستماع إلى موجز لأهم عناوين اليوم أو الاستماع إلى نص الخبر بالعربية عبر `Web Speech API`.
- **ملخص النقاط السريع (Smart Brief):** استخلاص أهم النقاط الرئيسية لكل خبر داخل صفحة القراءة.
- **مكتبتي (Bookmarks):** حفظ الأخبار المفضلة في المتصفح (`localStorage`) لقراءتها لاحقاً في أي وقت.

## التقنيات المستخدمة

- **HTML5 & CSS3** (Custom Properties, Bento Grid, Glassmorphism, Skeleton Shimmer)
- **Vanilla JavaScript (ES6+)** (History API Routing, Web Speech API, LocalStorage Bookmarks)
- **Vercel Serverless Functions** ([api/get-news.js](file:///c:/Users/MohD/WebstormProjects/lingramq8/api/get-news.js))
